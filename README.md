# 💕 Valentine's Day Website for Swati & Veda

A cute, interactive Valentine's Day website created with love for my wife Swati and daughter Veda!

## Features

✨ **Multi-screen Experience**: Journey through 7 beautiful screens with personalized messages

🎨 **Pastel & Pink Theme**: Beautiful gradient backgrounds with soft, romantic colors

💫 **Smooth Animations**: 
- Floating hearts background
- Bouncing text
- Rotating emojis
- Confetti celebration
- Button hover effects
- Screen transitions

🎮 **Interactive Elements**:
- Playful "No" buttons that run away when clicked
- Growing "Yes" buttons when hovering near "No" buttons
- Multi-question format addressing both Swati and Veda

💝 **Personal Messages**: Heartfelt messages for both my wife and daughter

## How to Use

Simply open `index.html` in any modern web browser!

## Deploying to GitHub Pages

1. Initialize git repository:
```bash
git init
git add .
git commit -m "Initial commit: Valentine's website for Swati and Veda"
```

2. Create a new repository on GitHub

3. Push to GitHub:
```bash
git remote add origin <your-repository-url>
git branch -M main
git push -u origin main
```

4. Enable GitHub Pages:
   - Go to repository Settings
   - Navigate to Pages section
   - Select "main" branch as source
   - Save and your site will be live!
